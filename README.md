# DownSuVid

تطبيق أندرويد لتحميل الفيديوهات مع معالجة ذكية للترجمة

## المميزات

- تحميل فيديوهات من مواقع متعددة باستخدام yt-dlp
- معالجة ذكية للترجمة (البحث عن الترجمة العربية أولاً)
- ترجمة آلية للترجمات إلى العربية
- توليد ترجمة صوتية باستخدام الذكاء الاصطناعي
- دعم الوضع الليلي والنهاري
- واجهة مستخدم باللغة العربية
- دعم RTL كامل

## المتطلبات

- Python 3.11
- Buildozer
- Android SDK/NDK

## التثبيت والتشغيل

```bash
# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل التطبيق على الحاسوب
python main.py

# بناء التطبيق للأندرويد
buildozer android debug deploy run
